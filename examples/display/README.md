# 显示控件参考示例

本目录包含 7 个示例，每个类各有一对 `.h/.cpp`，由 `widget_examples` 统一运行。

[用途、常用方式、操作步骤与完整代码](../../docs/examples/display.md) · [返回示例目录](../README.md)

| 控件 | 头文件 | 实现文件 | 示例功能 |
| --- | --- | --- | --- |
| QLabel | [labelexample.h](labelexample.h) | [labelexample.cpp](labelexample.cpp) | 同时展示可复制文字和程序生成的色块图片。 |
| QProgressBar | [progressbarexample.h](progressbarexample.h) | [progressbarexample.cpp](progressbarexample.cpp) | 定时器模拟进度，可切换确定进度和忙碌模式，支持重新开始。 |
| QTextBrowser | [textbrowserexample.h](textbrowserexample.h) | [textbrowserexample.cpp](textbrowserexample.cpp) | 内置帮助内容与锚点导航，不启动外部浏览器。 |
| QLCDNumber | [lcdnumberexample.h](lcdnumberexample.h) | [lcdnumberexample.cpp](lcdnumberexample.cpp) | 数值框调整模拟电压，LCD 回显带一位小数的读数。 |
| QCalendarWidget | [calendarwidgetexample.h](calendarwidgetexample.h) | [calendarwidgetexample.cpp](calendarwidgetexample.cpp) | 日历选择与日期回显，同时突出标记今天。 |
| QGraphicsView | [graphicsviewexample.h](graphicsviewexample.h) | [graphicsviewexample.cpp](graphicsviewexample.cpp) | 可拖动的矩形与椭圆，提供放大、缩小和复位。 |
| QFrame | [frameexample.h](frameexample.h) | [frameexample.cpp](frameexample.cpp) | 上方带边框的说明区域，下方使用水平分隔线。 |
