## 知识点

### 多行文本与纯文本读取

QTextEdit 支持多行文本和富文本。当前示例通过 `toPlainText()` 获取不带格式信息的 QString，再调用 `isEmpty()` 判断内容是否为空。

`isEmpty()` 判断的是字符串长度是否为零，只包含空格或换行的文本仍可能被视为非空。若以后需要过滤空白输入，应根据需求另做判断。

### 全选前设置焦点

“全选”按钮的槽函数依次执行：

```cpp
textEdit->setFocus();
if (!textEdit->toPlainText().isEmpty()) {
    textEdit->selectAll();
}
```

点击按钮后，把焦点交回文本框，方便继续进行复制、输入等键盘操作。非空时 `selectAll()` 选中内部文本框中的全部内容。

QTextEdit 也提供常用的复制、粘贴等操作，默认键盘快捷键受平台和快捷键绑定影响；本次示例只连接了全选与清除按钮。

### 清除文本

“清除”按钮调用 `textEdit->clear()`，移除内部文本框中的内容。当前槽函数没有再次调用 `setFocus()`，因此不会主动把焦点交回文本框。

### 信号槽与对象生命周期

两个按钮的 `clicked` 信号以函数指针形式连接到无参数槽函数。信号携带的 `bool` 参数未被使用，Qt 允许槽函数接收少于信号提供的参数。

文本框和两个按钮均以 `this` 为父对象创建。页面销毁时由 Qt 父子对象机制自动释放它们，当前不需要手写析构函数逐一删除子控件。

## 当前布局与限制

- `TextEdit` 本身继承 QTextEdit，又创建一个内部 QTextEdit；实际全选与清除只操作内部对象，外层编辑区域没有连接这些操作。后续需要统一页面结构时，可考虑使用 QWidget 作为页面容器。
- 外层构造函数设置的尺寸为 `400 × 300`，按钮从 `y = 300` 开始，高度 30，单独按此尺寸显示时按钮会位于页面边界之外。在主窗口中，QStackedWidget 会重新分配页面尺寸，最终显示效果需运行确认。
- 内部文本框及按钮使用固定坐标，缩放窗口、改变字体或平台样式时可能出现裁切、空白或位置不协调。
- 全选前的 `toPlainText()` 会获取整段纯文本，当前适用于简单练习；大文本场景应再考虑避免不必要的文本复制。
- 新增源码目前尚未提供完整的中文函数注释，后续修改函数实现时应按工程规范补充。
