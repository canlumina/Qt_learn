# QLineEdit：读取输入的文本并显示

日期：2026-11-16

## 本次做了什么

新增 `LineEdit` 示例页面，注册到主窗口左侧目录的 `QLineEdit` 项。页面上有一个输入框、一个“确认”按钮和一个标签。

在输入框里输入文字，点击“确认”后，标签显示“您输入的文本是：”加上输入的内容，同时清空输入框。

## 知识点

### 读取和清空输入框

```cpp
QString str = "您输入的文本是：" + lineEdit->text();
label->setText(str);
lineEdit->clear();
```

- `text()` 返回输入框当前的内容，类型是 `QString`。
- `QString` 可以直接用 `+` 拼接。
- `clear()` 清空输入框，等价于 `setText("")`。

### 用 QLabel 显示结果

`QLabel` 只负责显示文字，`setText()` 可以随时更新内容。本例用它代替之前示例里的 `qDebug()`，结果直接显示在界面上，不依赖终端。

### 点击按钮时才读取

本例把按钮的 `clicked` 信号连接到槽函数，点击时才读取输入框：

```cpp
connect(pushButton, &QPushButton::clicked, this, &LineEdit::on_pushButton_clicked);
```

QLineEdit 自己也有信号，可以不借助按钮：

| 信号 | 触发时机 |
| --- | --- |
| `textChanged(const QString &)` | 内容每变化一次就触发，包括代码里调用 `setText()` |
| `textEdited(const QString &)` | 只在用户手动编辑时触发 |
| `returnPressed()` | 在输入框里按下回车 |
| `editingFinished()` | 按下回车或输入框失去焦点 |

## 遇到的问题

### 注册这个示例后程序无法启动

现象：在 `mainwindow.cpp` 里加上 `addDemo("QLineEdit", new LineEdit(this));` 后，程序一启动就退出，窗口不出现；注释掉这一行又恢复正常。编译没有任何报错。

原因：构造函数里把 `QLineEdit` 写成了自己的类名 `LineEdit`，少了一个 `Q`：

```cpp
LineEdit::LineEdit(QWidget *parent)
    : QLineEdit(parent)
{
    lineEdit = new LineEdit(this);   // 错误：创建的是自己这个类
```

`LineEdit` 的构造函数里又创建一个 `LineEdit`，新对象的构造函数再创建一个，无限套下去，直到栈空间用完，程序崩溃。因为 `LineEdit` 继承自 `QLineEdit`，把它赋给 `QLineEdit *` 类型的成员是合法的，所以编译器不会报错。

解决：

```cpp
lineEdit = new QLineEdit(this);
```

排查方法：加上某一行就崩溃、去掉就正常，问题就在这一行调用到的代码里。这里是 `new LineEdit(this)`，所以直接看 `LineEdit` 的构造函数。自己的类名和 Qt 的类名只差一个 `Q` 时，容易出现这种笔误。

## 验证与限制

- 本次核对了新增源码、主窗口注册和 CMake 文件清单。
- 沿用此前要求，本次不执行编译，也没有运行程序；上面的崩溃原因是读代码得出的，修改后是否正常启动还需要重新编译确认。
- `LineEdit` 类继承的是 `QLineEdit`，不是其他示例使用的 `QWidget`，所以整个页面本身就是一个输入框，点击页面空白处也能输入文字。后续应改成继承 `QWidget`，同时把构造函数初始化列表改成 `: QWidget(parent)`。
- 输入框、按钮、标签都使用固定坐标和尺寸，高度只有 20 像素，字体较大时文字可能被裁切。
- 新增函数尚未提供中文函数注释。
