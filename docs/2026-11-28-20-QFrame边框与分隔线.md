# QFrame：带边框容器与水平分隔线

日期：2026-11-28

## 本次练习

在 `demos/display/frame.h / .cpp` 实现 `Frame` 页面，通过 `learn` 主窗口的 `QFrame` 项打开。页面继承 QWidget，使用 QVBoxLayout 从上到下排列说明文字、带边框的内容容器、水平分隔线和下方说明。

QFrame 既能作为容器包住一组控件，也能用作分隔线。本练习覆盖这两种用途：`StyledPanel` 展示带边框的内容区域，内部再设置布局放置 QLabel；`HLine` 在上下内容之间绘制水平线。需要垂直分隔时可进一步尝试 `VLine`。

## 关键代码

```cpp
auto *panel = new QFrame(this);
panel->setFrameShape(QFrame::StyledPanel);
panel->setFrameShadow(QFrame::Sunken);
auto *panelLayout = new QVBoxLayout(panel);
panelLayout->addWidget(new QLabel(tr("这是带边框的内容容器"), panel));

auto *line = new QFrame(this);
line->setFrameShape(QFrame::HLine);
line->setFrameShadow(QFrame::Sunken);
layout->addWidget(panel);
layout->addWidget(line);
layout->addWidget(new QLabel(tr("这是分隔线下方的说明"), this));
```

以上为代码节选，完整构造函数及页面布局见 `demos/display/frame.cpp`。

- `setFrameShape()` 决定边框或分隔线的形状；面板和线均使用 QFrame，无需自定义绘制。
- `setFrameShadow(QFrame::Sunken)` 指定凹陷效果；实际边框、颜色和阴影由当前样式绘制，可能随桌面主题变化。
- `new QVBoxLayout(panel)` 负责面板内部控件的排列，外层布局负责整个面板和分隔线的位置。
- 页面边距为 12，整体顶部对齐；当前是静态展示，没有按钮、信号槽或硬件访问。
- 页面、面板、标签及布局由 Qt 父子对象机制管理，无需额外析构函数释放资源；控件须在 GUI 线程创建和操作。
