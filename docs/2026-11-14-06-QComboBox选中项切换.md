# QComboBox：选择项变化时输出当前省份

日期：2026-11-14

## 本次做了什么

新增 `ComboBox` 示例页面，注册到主窗口左侧目录的 `QComboBox` 项。页面上放一个 QComboBox，添加“上海”“北京”“广州”三个选项。

切换选项时，槽函数取得当前选项的序号，通过 `qDebug()` 输出对应的文字。界面上没有显示结果，只能从调试输出里看到。

这是 `demos/inputs/` 下的第一个输入控件示例。

## 知识点

### 添加选项

```cpp
comboBox->addItem("上海");
```

`addItem()` 每次追加一项。选项内部按插入顺序从 0 开始编号，这个编号就是“索引”。也可以用 `insertItem()` 在指定位置插入，或用 `addItems()` 一次添加多个。

### 用函数指针连接带重载的信号

```cpp
connect(comboBox, QOverload<int>::of(&QComboBox::currentIndexChanged),
        this, &ComboBox::comboBoxIndexChanged);
```

`currentIndexChanged` 有两个重载：一个参数是 `int` 索引，一个是 `QString` 文本。直接写 `&QComboBox::currentIndexChanged` 编译器无法确定选哪一个，会报“重载函数无法解析”。`QOverload<int>::of(...)` 明确指定选参数为 `int` 的那个版本。

等价的字符串写法是：

```cpp
connect(comboBox, SIGNAL(currentIndexChanged(int)), this, SLOT(comboBoxIndexChanged(int)));
```

两种写法效果相同。字符串写法编译期不检查类型，写错了要到运行时才会在控制台提示连接失败；函数指针写法拼错或参数不匹配会直接编译报错，更早发现问题。本例把字符串写法保留在注释里，方便对照。

### 用索引取得选项文字

```cpp
qDebug() << "您选择的省份是:" << comboBox->itemText(index);
```

槽函数收到的是索引，`itemText(index)` 按索引取回文字。另一种做法是直接连接 `QString` 版本的重载，槽函数直接拿到文字：

```cpp
connect(comboBox, QOverload<const QString &>::of(&QComboBox::currentIndexChanged),
        this, &ComboBox::某槽函数);
```

两种方式各有用途：在需要和别的控件按编号对应时用索引更方便。

### 通过 qDebug() 输出日志

`qDebug()` 是 Qt 的调试输出流，输出的内容出现在启动程序的终端里（Qt Creator 中在“应用程序输出”面板）。可以连续用 `<<` 拼接不同内容，会自动加空格分隔。需要注意：它依赖控制台，嵌入式开发板上如果直接从系统启动程序，可能看不到输出。
