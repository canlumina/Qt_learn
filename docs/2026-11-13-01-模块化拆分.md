## 主窗口是怎么工作的

中心区域用 `QHBoxLayout` 左右分成两块：

- 左边 `QListWidget`：示例目录，每个示例占一行。
- 右边 `QStackedWidget`：放所有示例页面，一次只显示其中一页。

两者用一条信号槽连起来：点击目录的第 n 行，右边就切到第 n 页。

```cpp
connect(listWidget, SIGNAL(currentRowChanged(int)),
        stackedWidget, SLOT(setCurrentIndex(int)));
```

`MainWindow::addDemo(标题, 页面)` 同时往两边各加一项，所以目录的行号和页面的序号始终对应。

## 以后新增一个控件示例

以 QCheckBox 为例：

1. 在 `demos/` 下新建 `checkboxdemo.h` 和 `checkboxdemo.cpp`，类继承 `QWidget`，照着 `radiobuttondemo` 的写法来。
2. 在 `CMakeLists.txt` 的 `add_executable()` 里加上这两个文件。
3. 在 `mainwindow.cpp` 里 `#include "demos/checkboxdemo.h"`，并在“示例注册处”加一行：
   ```cpp
   addDemo("QCheckBox", new CheckBoxDemo(this));
   ```

## 知识点

- **QPushButton 的信号槽**：`clicked()` 信号连接到自己写的槽函数，槽函数要声明在头文件的 `private slots:` 下面。
- **页面内的坐标是相对坐标**：示例页面里 `setGeometry()` 的坐标相对于页面自己，不是相对于整个窗口。所以按钮在屏幕上比拆分前靠右 150 像素（左侧目录的宽度）。
- **样式表选择器**：换背景写成 `PushButtonDemo { background-color: ...; }`，只作用于页面本身。不写选择器的话，背景色会一起传给页面里的按钮。

## 遇到的问题

### `setGeometry()` 设置的窗口大小被覆盖

现象：构造函数里写了 `setGeometry(0, 0, 800, 480)`，实际窗口却是 800x600。

原因：`ui->setupUi(this)` 会按 `.ui` 文件里的尺寸（800x600）重新设置窗口大小，写在它前面的 `setGeometry()` 就被覆盖了。

解决：把 `setGeometry()` 放到 `setupUi()` 之后。

### 自定义 QWidget 子类设置背景色没反应

原因：直接继承 `QWidget` 的自定义类，默认不绘制样式表里的背景。

解决：构造函数里加一句：

```cpp
this->setAttribute(Qt::WA_StyledBackground, true);
```
