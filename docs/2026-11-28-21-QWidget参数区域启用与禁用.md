# QWidget：参数区域整体启用与禁用

日期：2026-11-28

## 本次练习

在 `demos/containers/widget.h / .cpp` 实现 `Widget` 页面，通过 `learn` 主窗口的 `QWidget` 项打开。页面使用 QVBoxLayout 放置说明文字、“启用参数区域”复选框和参数容器，容器内部使用 QFormLayout 排列名称输入框与目标值输入框。

QWidget 是 Qt 窗口部件的基础类，也可以直接作为一组控件的父容器。常见用法是创建 QWidget，为它设置布局，再把子控件放入布局，统一管理这一组内容的显示、启用状态和生命周期。

本练习默认勾选复选框，参数区域可用；取消勾选后，名称和目标值输入框一起禁用；重新勾选后恢复可用，已输入的内容保留。目标值范围为 0～100，初始值为 0。当前只编辑模拟参数，不保存配置或访问硬件。

## 关键代码

```cpp
auto *enabled = new QCheckBox(tr("启用参数区域"), this);
enabled->setChecked(true);
auto *panel = new QWidget(this);
auto *panelLayout = new QFormLayout(panel);
panelLayout->addRow(tr("名称："), new QLineEdit(panel));
auto *value = new QSpinBox(panel);
value->setRange(0, 100);
panelLayout->addRow(tr("目标值："), value);
layout->addWidget(enabled);
layout->addWidget(panel);

connect(enabled, &QCheckBox::toggled, panel, &QWidget::setEnabled);
```

以上为代码节选，完整构造函数及页面布局见 `demos/containers/widget.cpp`。

- `new QFormLayout(panel)` 直接将表单布局安装到参数容器上，负责排列容器中的标签和输入控件。
- 两个输入控件均明确以 `panel` 为父控件，使对象关系与界面分组一致。
- `toggled(bool)` 将复选框状态传给 `panel->setEnabled(bool)`，父容器禁用时，其子控件也随之禁用。
- 复选框放在参数容器外部，因此禁用参数区域后仍可操作复选框并重新启用区域。
- 禁用只改变可操作状态，不会清空输入内容；重新启用后可以继续修改原有参数。
- 页面、容器、布局和子控件由 Qt 父子对象机制管理，无需额外析构函数释放资源；所有界面操作须在 GUI 线程执行。
