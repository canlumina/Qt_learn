# QLabel：可复制文字与色块图片切换

日期：2026-11-27

## 本次练习

根据 `examples/display/` 的标签示例，在 `demos/display/lable.h / .cpp` 实现 `Lable` 页面，通过 `learn` 主窗口的 `QLabel` 项打开。保留当前类名和文件名，页面继承 QWidget，使用 QVBoxLayout 纵向排列说明、文本标签、图片标签和按钮。

QLabel 常用于输入项说明、设备状态或图片展示。本练习显示“状态：设备空闲”和一段可选择并复制的文字，通过 `setWordWrap(true)` 自动换行，通过 `setTextFormat(Qt::PlainText)` 明确按纯文本显示。

图片由程序创建，尺寸为 160×80，初始颜色为蓝色，无需读取外部图片文件。点击“改变颜色”切换到橙色，再次点击恢复蓝色；按钮使用可选中状态，连接 `toggled(bool)` 完成图片更新。

## 关键代码

```cpp
auto *text = new QLabel(tr("状态：设备空闲\n这段文字可以选择并复制。"), this);
text->setWordWrap(true);
text->setTextFormat(Qt::PlainText);
text->setTextInteractionFlags(Qt::TextSelectableByMouse);

auto *image = new QLabel(this);
QPixmap pixmap(160, 80);
pixmap.fill(QColor("#377bb5"));
image->setPixmap(pixmap);
image->setAlignment(Qt::AlignCenter);

auto *change = new QPushButton(tr("改变颜色"), this);
change->setCheckable(true);
/**
 * @brief 根据按钮状态切换色块
 * @param checked true 显示橙色，false 显示蓝色
 * @note 无返回值；在 GUI 线程执行，页面销毁后连接自动断开。
 */
connect(change, &QPushButton::toggled, this, [image](bool checked) {
    QPixmap next(160, 80);
    next.fill(checked ? QColor("#c77a35") : QColor("#377bb5"));
    image->setPixmap(next);
});
```

以上为代码节选，完整布局和构造函数见 `demos/display/lable.cpp`。

- `setTextInteractionFlags(Qt::TextSelectableByMouse)` 允许鼠标选择文本，选中后可尝试 `Ctrl+C` 复制；该标签不提供文本编辑。
- `setPixmap()` 设置图片，`setAlignment(Qt::AlignCenter)` 将图片放在标签可用区域的中间；图片保持当前尺寸，未启用随标签缩放。
- `setCheckable(true)` 让按钮保留选中状态，`toggled(bool)` 携带当前状态，用于决定图片颜色。
- 布局与子控件由 Qt 父子对象机制管理，QPixmap 是局部值对象；当前没有需要自定义析构函数释放的外部资源。
- 信号连接以页面 `this` 为上下文，页面销毁后连接自动断开；所有控件和图片操作在 GUI 线程进行。
