# QTextEdit：从基础操作到富文本编辑器

日期：2026-11-23

## 这次扩展了什么

在已有 QTextEdit 示例中实现一个小型富文本编辑器。页面改为继承 QWidget，通过布局管理器组织编辑工具栏、格式工具栏、文本框、查找区和统计区。打开主窗口中的 `QTextEdit` 页面即可使用。

所有新增和修改函数都在 `textedit.h` 中提供中文注释，说明功能、参数、返回值和 GUI 线程调用限制；实现中另有关键行为注释。

| 功能 | 操作及行为 |
| --- | --- |
| 字符格式 | 加粗、斜体、下划线、8～48 pt 字号和文字颜色 |
| 段落格式 | 左对齐、居中、右对齐、两端对齐 |
| 编辑操作 | 剪切、复制、粘贴、全选，以及可撤销的清空全文 |
| 历史记录 | 撤销、重做；按钮随历史状态自动启用或禁用 |
| 文本查找 | 不区分大小写查找下一处，到文末后从头继续；空关键字及未找到时有提示 |
| 实时统计 | 文档字符数、段落数、选中字符数 |
| 初始化 | 使用 `setHtml()` 提供带标题和多段正文的练习内容 |

剪切和复制仅在存在选区时启用。查找后保留查找框焦点，可连续按回车寻找下一处；点击编辑区后可继续输入。

## 建议练习顺序

1. 选中示例正文的几个字，依次设置加粗、颜色和字号；观察未选中的文字保持原格式。
2. 取消选区，将光标放在正文中，再改变斜体或下划线并输入新文字；观察格式作用于后续输入。
3. 把光标放在第二段，选择“居中”；再选中多段文字，改变段落对齐。
4. 点击“撤销”和“重做”，观察文字内容及格式恢复。
5. 点击“清空”，再点击一次“撤销”，检查全文及格式恢复。
6. 搜索“文字”，连续按回车，观察末尾回到开头的提示；再搜索不存在的内容，检查原光标和选区保留。
7. 输入中文、换行和 emoji，再全选，观察字符数和选中数。

以上为建议练习步骤。用户后续已确认完成编译测试，未提供逐项测试结果。

## 关键实现

### 字符格式只合并本次修改的属性

每个格式槽先创建 QTextCharFormat，只设置所需属性，再调用 `mergeCurrentCharFormat()`。例如加粗只修改字重，不会覆盖字号、颜色和斜体。

有选区时修改选中文字；没有选区时设置后续输入的格式，不自动选中整词。`mergeFormat()` 将焦点交回编辑区，便于继续输入。

颜色对话框取消时返回无效 QColor，代码检查 `isValid()`，避免把取消操作应用到文档。

### 字符格式和段落格式分开处理

字符格式描述字重、斜体、下划线、字号和前景色；段落对齐使用 `setAlignment()`，作用于当前段落或选中的段落。

工具栏通过 `currentCharFormatChanged` 和 `cursorPositionChanged` 回显光标处格式。选区包含不同格式时，工具栏显示当前光标处的格式，不提供“混合格式”三态显示。

### QSignalBlocker 防止回显误改文档

调用 `setChecked()`、`setValue()` 或 `setCurrentIndex()` 更新工具栏，也可能触发连接的槽函数。`syncFormatControls()` 使用 QSignalBlocker 临时阻断这些信号，退出作用域后自动恢复原信号状态。

这样移动光标或执行查找只更新显示，不会因此修改文档或产生撤销记录。

### 清空也能撤销

`QTextEdit::clear()` 会重置撤销历史。本示例用 QTextCursor 选择全文并调用 `removeSelectedText()`，通过 `beginEditBlock()` / `endEditBlock()` 把删除作为一个编辑操作。

因此清空后可以一次撤销恢复原有内容及其格式。初始化使用的 `setHtml()` 会重置历史，只在构造函数中调用。

### 查找与计数

`find()` 找到匹配后将其选中。第一次找不到时将光标移至开头，再查找一次；仍找不到则恢复原光标和选区。查找不会修改文档内容。

字符数通过 `toPlainText().toUcs4().size()` 统计 Unicode 码点，包含空格、换行等字符。某些由多个码点组成的 emoji 或带组合符号的文字仍计为多个字符，这不是“用户看到的字形数”，也不是单词数。

段落数使用 `QTextDocument::blockCount()`，不等于自动换行后的视觉行数；空文档通常仍包含一个空段落。
