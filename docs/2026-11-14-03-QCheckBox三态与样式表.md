# QCheckBox：三态切换与图片样式

日期：2026-11-14

## 当前示例做了什么

在 `demos/checkboxdemo.h / .cpp` 中创建一个 QCheckBox，开启三态模式。点击复选框后，槽函数根据状态更新文字；`style.qss` 为三种状态分别设置图片。

主窗口已经注册 QCheckBox 页面，在左侧目录点击 `QCheckBox` 即可切换到这个示例。

## 知识点

### 三种状态

QCheckBox 默认是两态复选框。调用 `setTristate(true)` 后，可以表示“部分选中”。

| Qt 状态 | 数值 | 含义 | 当前槽函数显示的文字 |
| --- | --- | --- | --- |
| `Qt::Unchecked` | 0 | 未选中 | `Unchecked` |
| `Qt::PartiallyChecked` | 1 | 部分选中 | `PartiallyChecked` |
| `Qt::Checked` | 2 | 完全选中 | `Checked` |

部分选中常用于表示一组选项中只有一部分被选中。当前示例演示状态切换，没有实现父子复选框之间的联动。

```cpp
checkBox->setCheckState(Qt::Checked);
checkBox->setTristate(true);
```

当前代码先设置完全选中，再开启三态模式，这样可以正常初始化。开启三态主要决定用户点击时是否经过部分选中状态。

默认点击循环是：未选中 → 部分选中 → 完全选中 → 未选中。当前初始状态为完全选中，因此首次点击后变为未选中。

### 使用带参数的信号槽

```cpp
connect(checkBox, SIGNAL(stateChanged(int)),
        this, SLOT(checkBoxStateClicked(int)));
```

`stateChanged(int)` 在选中状态改变时发出，把新状态传给槽函数。槽函数中的 `switch (state)` 根据三个 Qt 枚举值调用 `setText()`。

这里监听的是状态变化，程序调用 `setCheckState()` 改变状态也可以触发信号，并不只响应鼠标点击。槽函数名虽然包含 `Clicked`，实际处理的是状态变化。

当前写法使用 Qt 的字符串形式信号槽，头文件需要 `Q_OBJECT` 和 `private slots:`，构建需要开启 AUTOMOC。`stateChanged(int)` 在 Qt 6.9 起被标记为弃用；较新的 Qt 6 可使用 `checkStateChanged(Qt::CheckState)`，但兼容旧 Qt 5 时需要考虑版本差异。

### 初始选中状态与初始文字是两回事

当前构造函数的顺序是：设置 `Qt::Checked` → 设置“初始化显示的文本” → 开启三态 → 连接信号槽。

设置初始状态时尚未连接槽函数，所以初次进入页面时，图片是完全选中图片，文字仍是“初始化显示的文本”。第一次点击改变状态后，文字才由槽函数更新。这与当前代码一致。

### 用样式表设置三种图片

```css
QCheckBox::indicator {
    width: 50px;
    height: 50px;
}
QCheckBox::indicator:enabled:unchecked {
    image: url(:/images/unchecked.png);
}
QCheckBox::indicator:enabled:checked {
    image: url(:/images/checked.png);
}
QCheckBox::indicator:enabled:indeterminate {
    image: url(:/images/indeterminate.png);
}
```

`::indicator` 指复选框前面的状态指示器。Qt 枚举中的 `PartiallyChecked` 在 QSS 中对应 `:indeterminate`，不能直接写成 `:partiallychecked`。

这些图片规则带有 `:enabled`，只匹配启用状态。当前示例没有定义禁用状态专用图片。

`QCheckBox` 规则中的 `spacing: 5px` 控制指示器与文字的间距；`CheckBoxDemo` 规则设置页面背景。自定义 QWidget 页面开启 `Qt::WA_StyledBackground`，使样式表背景能够绘制。
